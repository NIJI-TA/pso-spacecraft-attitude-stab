# Particle Swarm Optimization (PSO)

### Реализация поиска оптимальных коэффициентов управления для спутника методом роя частиц

- задача была поставлена научным руководителем и руководителем гранта
- важно применить полученные при работе над курсовой навыки и знания, а так же сам код, чтобы получить работающую программу по поиску оптимального управления теперь уже спутником
- сроки не поджимают, но работаем в темпе
- вся теоретическая информация и литература в тг группе.
